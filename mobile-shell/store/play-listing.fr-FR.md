## Description courte pour téléphone (80 caractères max)

Gardez liens et notes. Lisez votre bibliothèque téléchargée hors ligne.

## Description complète pour téléphone

Enregistrez des liens et des notes sur votre téléphone, importez les ZIP/JSON
Instagram Saved et organisez le contenu disponible. Le partage crée un brouillon ;
vérifiez-le et appuyez sur Enregistrer. L’IA Wiskit facultative, avec votre propre
clé, répond aux questions à partir de votre contenu et de références aux sources.
Les frais et conditions du fournisseur s’appliquent séparément.

Utilisez le téléphone seul ou associez-le à votre bibliothèque Windows. La
synchronisation Google Drive facultative stocke le contenu chiffré dans votre
compte Google ; les appareils associés détiennent les clés de déchiffrement, et
Google peut voir la taille des fichiers et les métadonnées de mise à jour. Lisez
le contenu enregistré hors ligne. L’IA, les aperçus et la synchronisation nécessitent
une connexion réseau. Les téléchargements, le scraping et l’analyse vidéo se font
sous Windows ; le mode PC direct nécessite un PC en marche et accessible. Les
aperçus et la disponibilité des médias dépendent du site source.

Toutes les fonctions actuelles sont disponibles sans paiement ni reçu. Le soutien
facultatif aide le développeur à poursuivre son travail. Lisez la licence du code
source et la Politique de confidentialité dans Plus. Dissocier ou vider un cache
n’efface pas toutes les copies sur les appareils ou dans le cloud ; la désinstallation
sous Windows conserve les données du bureau par défaut.
