# Brainamon 隱私權政策

最後更新：2026-10-28

賣方與隱私聯絡人：Frederic TOMAS（個人），電子郵件 me@fredtomas.com。本政策公開版本：https://www.fredtomas.com/brainamon/privacy/

Brainamon 會在你的裝置上儲存一個資料庫。Windows 桌面版、手機獨立模式、Google 雲端硬碟鏡像模式與直連電腦模式使用不同的連線方式，說明如下。儲存連結與筆記不需要任何 AI 金鑰。外部 AI 處理與 Google 雲端硬碟同步皆為選用功能。閱讀隨附的政策、軟體授權與聲明不需要連線至任何服務商。

## 本機資料與憑證

- 在 Windows 上，所選的資料資料夾保存已儲存的連結、中繼資料、縮圖與媒體、筆記、逐字稿、報告、畫布、對話與設定。「設定 > 應用程式」會顯示資料資料夾。設定所在位置通常為 `%LOCALAPPDATA%\Brainamon`、沿用的既有 `%LOCALAPPDATA%\Content Manager`，或明確指定的 `BRAINAMON_HOME`。從原始碼執行時通常使用儲存庫中的 `data/` 與 `local/`；自訂位置可能不同。

- API 金鑰、Google 授權、鏡像金鑰與明確匯入的網站工作階段，保存在設定所在位置，不包含在一般的資料庫或雲端硬碟匯出中。Windows 以目前使用者的 DPAPI 與存取限制保護應用程式管理的機密檔案。資料庫檔案本身並未全部由 Brainamon 加密。此保護無法阻止使用你已解鎖帳戶的人，或具有相同權限的惡意軟體存取。

- 社群網站的 Cookie 與擷取工具記住的登入資訊，是你選擇存取之網站的憑證。匯入、記住登入資訊以及將其複製用於下載，皆為明確的選擇。「忘記已儲存的存取」會停止應用程式使用並移除應用程式管理的機密；但不會撤銷該網站的工作階段，也不會刪除你原始的匯出檔、瀏覽器設定檔或備份。

- 手機會在瀏覽器或應用程式的本機儲存空間中保存資料庫項目、已下載或開啟的檔案、離線副本、草稿與待同步的變更。解密後的資料庫內容可能留在裝置上。Android 應用程式使用以 Android Keystore 為基礎的加密儲存空間保存配對與 AI 金鑰及 Google 權杖，並將應用程式資料排除在 Android 備份之外。此保護不適用於一般瀏覽器儲存空間，也不代表已下載的資料庫內容在裝置上是加密保存的。

- 桌面版的錯誤記錄與應用程式內診斷資訊皆保存在本機。其中可能包含檔案路徑、錯誤、操作細節以及請求或回應的內容。應用程式不會自動將當機報告或分析資料上傳給開發者。選擇傳送記錄或支援資料前，請先檢查並遮蔽敏感內容；請勿包含金鑰、配對碼或 Cookie 匯出檔。

## 選用的 AI 處理

AI 請求會從執行操作的裝置，傳送到你選擇的服務商或設定的端點（相容 OpenAI、本機或代理伺服器）。代理伺服器可能把請求轉送給其他服務商；標示為「本機」的伺服器，只有在其設定位址確實位於本機時才是本機。直連電腦模式下，手機會把請求送到執行中的電腦，由電腦進行外部處理。手機獨立或鏡像模式中使用自有金鑰的功能，會使用手機支援的服務商。

視操作而定，送出的內容可能包括問題、對話記錄、資料庫中的標題、網址、描述、說明文字、筆記、逐字稿或報告摘錄、檢索到的上下文、你提供的圖片、PDF 文件或選取的影片畫面。手機以自有金鑰閱讀 PDF 時會上傳完整 PDF；直連電腦或桌面版閱讀 PDF 時，則在電腦上擷取文字。在手機上新增 PDF 會立即開始閱讀。搜尋索引與部分 Deep 研究會傳送資料庫文字以產生向量嵌入；語意查詢會傳送查詢文字。影片分析可能把擷取的音訊上傳至 OpenAI 進行轉錄，並將畫面與文字傳送給選定的分析服務商。語音筆記會把錄製的音訊上傳至 OpenAI 進行轉錄。讀取圖片的功能會將所選圖片傳送給設定的視覺服務商。桌面版語音筆記的暫存音訊會在處理後排定清除。手機錄音可能在本機排隊，直到轉錄與儲存成功，並在恢復連線時自動上傳。影片分析擷取的音訊、畫面與下載的媒體，可能依該操作的保留選項而留存；逐字稿與報告會保留在資料庫中直到被刪除。在原始碼安裝中選擇 Claude Code 模式，也會使用你另行設定的 Claude Code 服務與權限。

API 憑證用於驗證這些請求。服務商或 API 費用與對 Brainamon 的自願贊助分開計算。服務商或代理伺服器的條款規範其對輸入、輸出、保留期限及任何訓練用途的處理方式；Brainamon 不保證服務商會立即刪除資料、永不用於訓練，或將資料保存在特定國家。傳送敏感內容前，請先查閱你所用端點與服務商的現行條款。移除本機金鑰只會停止該應用程式副本日後的使用；不會向發行者撤銷該金鑰，也不會清除已在外部處理過的請求。

## 請求的網路存取與其他應用程式

擷取預覽、說明文字、網頁或媒體時，會連線至所請求的網站及其內容主機，並傳送所請求的網址與一般連線資訊，例如你的 IP 位址與請求標頭。你選擇的網站憑證只會在相關的存取流程中使用。部分預覽會在貼上或分享連結後發出請求。來源網站自行管理其記錄、可用性與條款。瀏覽器擷取與影片下載或分析在電腦上執行；雲端硬碟鏡像是檔案同步，不提供與電腦工作的即時連線。

已安裝的 Windows 版本預設每天檢查 GitHub 並自動下載更新；可在「設定 > 應用程式」中關閉。手動檢查與下載仍可使用。檢查時會包含應用程式版本；下載會連線至 GitHub 的發行版本主機。安裝一律等待你明確按下「安裝並重新啟動」。安裝選用工具時會連線至相關套件、工具或瀏覽器的下載服務。這些服務會收到一般的連線與下載資訊。本機資料庫不會包含在檢查更新的請求中。

分享連結會建立本機草稿；按下「儲存」才會正式建立。手機上的編輯可在本機排隊，並在與受信任的電腦配對後，以加密方式經由雲端硬碟傳回電腦。目前的應用程式使用加密的 access-v2 記錄，其中包含鏡像指紋、核發與到期時間及啟用旗標，並由配對時取得的電腦金鑰簽署。不需要收據或持有人資訊。若已儲存既有的有效收據，電腦也會為舊版手機應用程式續期舊式 license-v1 記錄；這些記錄包含已簽署的收據（持有人、選填的電子郵件、ID 與核發日期）。這兩種記錄都不會傳送至授權伺服器，也不包含在 QR 碼中。電腦在執行且已登入時會續期存取許可。移除所有手機的操作會經由雲端硬碟傳遞，或最後一次的許可會在離線一小時內到期。移除舊式收據不會撤銷目前的配對或同步；舊版手機應用程式在舊式證明不再續期時需要升級。存取遭拒時，手機上的本機內容與排隊中的編輯仍可使用。手機獨立模式的使用者，可選擇在沒有電腦或授權的情況下，將資料庫日誌加密備份到 Google 雲端硬碟。此備份使用獨立的金鑰與分開的檔案，即使同一帳戶也存有桌面版資料庫亦然。還原時需要同一個 Google 帳戶與手機的復原碼；AI 金鑰不包含在內。匯出與「在 Obsidian 中開啟」會把所選內容交給你指定的目的地；這些匯出副本有其各自的保留期限。Android 的 QR 碼掃描使用 Google Play 服務的條碼掃描器；Brainamon 只接收掃描到的文字，本身不要求相機權限。Android 版包含 Google 的條碼掃描器與 ML Kit 元件。Google 的 ML Kit 條款表示其輸入處理在裝置上進行，而 SDK 可能連線至 Google 取得修正、模型與相容性更新，並將 API 效能與使用量指標傳送給 Google。請參閱 https://developers.google.com/ml-kit/terms 及 Google 隱私權政策 https://policies.google.com/privacy。實際發行的 SDK 與裝置行為仍需在發行時驗證；本應用程式不保證所有 Android 相依元件都不會發出外部請求。

## 選用的 Google 雲端硬碟同步

Google 授權使用 `drive.appdata`，也就是存取 Brainamon 專用的隱藏應用程式資料區，而非你一般的雲端硬碟檔案。在你連結並啟用之前，雲端硬碟功能保持關閉。電腦會先以 AES-256-GCM 加密鏡像內容再上傳；配對的裝置持有解密所需的金鑰。手機獨立模式也可在該處儲存加密的變更。選用的 Obsidian 筆記庫同步，會經由應用程式的加密雲端硬碟流程傳送其設定的內容。Google 會收到你的帳戶與連線資訊，並能看到檔案數量、大小與變更時間。內容加密並不會隱藏這些中繼資料，也無法阻止持有金鑰的裝置或人員存取。

配對碼與復原碼含有資料庫的金鑰資料。任何持有該代碼與 Google 帳戶的人，都可能讀取對應的資料庫。AI 金鑰的轉移需在電腦上另外選擇：所選金鑰會以一次性的轉移金鑰封存，30 分鐘後即無法再領取，成功領取後即刪除。清除失敗或離線時，可能會留下已過期的密文，直到之後經授權的清除為止；過期並不保證遠端的每一個位元組都已在當時消失。資料庫金鑰本身不會隨該次轉移而過期。請妥善保密代碼及剪貼簿中的副本。

已配對的手機也會在同一隱藏區域保存一筆以資料庫金鑰封存的小型記錄：裝置名稱（Android 裝置名稱，否則為製造商與型號；瀏覽器中為 "Phone browser"）及上次同步時間，讓電腦能在 Settings > Backup & phones（設定 > 備份與手機）中列出該手機。手機讀取資料庫後，會在原處取代這筆記錄，最多每 30 分鐘一次（名稱或配對變更時立即更新）。手機上的 Unpair 會嘗試刪除它（失敗時會留在雲端硬碟）；電腦上的 Remove all phones 會在金鑰輪替的清理階段，刪除以舊金鑰封存的記錄。不搭配電腦使用的手機不會寫入此記錄。

選用的「復原」設定，會將資料庫主金鑰的封套上傳到同一個隱藏的雲端硬碟區域：一份以通關密語保護，另一份獨立以復原組密鑰保護。通關密語的包裝金鑰由 Scrypt 推導；每個封套以 AES-256-GCM 加密。復原中繼資料包含格式與版本、帳戶、資料庫識別、指紋、世代與設定時間。明文的通關密語與復原組密鑰不會傳送給 Google 或賣方。復原組或手機上明確匯出的復原資料含有敏感的金鑰資料，存放位置由你決定。單憑 Google 登入無法解密鏡像；若遺失所有復原密鑰與裝置，可能無法再復原。在新電腦上還原，會將最新可用的鏡像下載到另一個本機資料庫；這並非保留的版本歷史，也不是完整的電腦或憑證備份。

Google 持有的資料適用 Google 的服務條款與保留政策。中斷連線不等於刪除鏡像，也不等於撤銷另一支手機的 Google 授權。

Brainamon 只使用 Google 雲端硬碟的應用程式資料存取權，為你的裝置儲存、讀取與刪除其自身的加密鏡像、變更、轉移與復原檔案。它不會讀取你其他的雲端硬碟檔案，也不會將 Google 使用者資料傳送給賣方。從鏡像讀取的資料庫內容，只有在你主動指示時才會傳給第三方，例如你傳送給自己 AI 服務商的問題。Brainamon 不會將 Google 使用者資料用於廣告，也不會用來訓練 AI 模型。Brainamon 對於從 Google API 取得之資訊的使用與傳輸，遵守 Google API 服務使用者資料政策 (https://developers.google.com/terms/api-services-user-data-policy)，包括「有限使用」的要求。

## 自願贊助與過往購買資訊

Brainamon 目前的功能不需要購買或啟用。自願贊助連結會開啟外部服務，適用該服務自身的隱私權政策與付款條款。過往購買與明確選擇的舊式收據換發仍可能使用 Gumroad。應用程式沒有 Brainamon 客戶帳號、商店或信用卡輸入系統。Gumroad 依其自身條款與隱私權政策（https://gumroad.com/privacy）處理結帳、付款、銷售稅、收據、下載交付與退款申請；信用卡資料會交給 Gumroad 及其付款處理商，絕不會交給賣方或應用程式。

賣方會透過 Gumroad 收到 Gumroad 與賣方共享的訂單資料，例如你的電子郵件、姓名、國家、購買的產品、支付的價格與退款狀態。只有在你明確儲存舊式收據時，應用程式才會將你 Gumroad 收據上的授權金鑰傳送一次到賣方位於 fredtomas.com 的啟用服務，該服務向 Gumroad 確認購買有效且未退款後，傳回舊式 Brainamon 授權金鑰；該金鑰帶有購買時的姓名與電子郵件，並儲存在你電腦上的應用程式中。除了主機供應商的標準存取記錄外，啟用服務不保留任何請求記錄。賣方也會收到你為了取得支援而選擇傳送的內容：電子郵件、附件或診斷資料。這些資料僅用於交付購買項目與授權、回覆支援與隱私請求、處理退款或爭議，以及保存必要的會計記錄。它們不會被出售，不會用於廣告，也不會用於無關的行銷。訂單記錄保留在 Gumroad，不會複製到其他服務，但賣方重新核發金鑰所需的授權資料，以及保存在賣方信箱中的支援郵件除外。資料只在上述目的所需期間，以及法定會計保存期間內保留。

開發者無法因隱私請求而遠端查看你的本機資料庫，正常使用應用程式時也不會自動收到其內容。

Gumroad、AI 服務商與 Google 可能依其自身政策與傳輸保障措施，在你所在國家以外處理資訊。

## 資料保留與刪除

本機的資料庫與設定資料會保留到你刪除為止；快取可能會被清理，但離線副本與待同步的變更會保留。備份與匯出是分開的副本。完整的備份或刪除步驟，請參閱專案文件中附帶的 `docs/BACKUP-RESTORE.md`。

1. 移除副本前，請先檢查手機上待同步的編輯與草稿，保留或送出你需要的內容。刪除項目或筆記請使用資料庫原有的操作；在鏡像模式下，從手機排入的電腦端刪除，要等電腦接收後才會生效。

2. 若要從雲端硬碟移除電腦所擁有的鏡像資料庫檔案，請在仍有授權時使用Settings > Backup & phones > Disconnect Google Drive...（設定 > 備份與手機 > 中斷 Google Drive 連線...），並選取 Also delete the backup from Google Drive（同時從 Google Drive 刪除備份），然後確認 Delete and disconnect（刪除並中斷連線）。請等待操作成功完成。此操作針對目前鏡像清單所識別的檔案，而非雲端硬碟中的每個物件、獨立模式日誌、筆記庫匯出、未知或舊檔案，或服務商的備份。失敗或離線的嘗試並不算完成刪除。其他保留的應用程式資料，請透過 Google 提供的控制項檢視。

3. 在每支手機上，Settings > Backup & phones > Unpair this phone（設定 > 備份與手機 > 解除此手機配對；獨立模式為 Remove from this phone，從此手機移除）會移除該連線。已儲存的離線檔案與部分待同步或本機記錄可能仍會保留。檢查完尚未送出的內容後，若要移除所有應用程式儲存資料，請使用 Android 的清除應用程式儲存空間功能或解除安裝；在瀏覽器中，請清除 Brainamon 網站的儲存資料。另外匯出的檔案請自行刪除。Settings > Storage > Clear the phone's copy（設定 > 儲存空間 > 清除手機副本）只會清除快取：離線檔案與尚未送出的變更仍會保留，立即重新整理也可能再次下載資料庫。

4. 在 Windows 上，請先記下「設定 > 應用程式」中所選的資料資料夾與實際的設定位置，然後完全結束應用程式，包括背景與系統匣程序。互動式解除安裝會提供永久刪除本機資料的選項；預設為保留資料，靜默解除安裝也會保留。選擇刪除後，會列出設定與資料庫資料夾供第二次確認，包括在設定位置以外找到的自訂資料庫。請檢查每個路徑並確認已有需要的備份後再確認：所列資料夾內的所有內容都會被刪除。遇到不安全或無法辨識的路徑或發生錯誤時，清除會停止。未列出的自訂或舊資料夾請另行檢查。
