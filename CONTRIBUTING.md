# Contributing to Brainamon

The GPL source edition is being prepared. The LICENSE at the exact revision you
use governs that revision; historical downloads retain their original terms.

For the public GPL edition, submit application-code contributions under
GPL-3.0-only. Include attribution and the original license for third-party work.
Only submit material you have permission to contribute. No copyright assignment
or additional linking exception is requested.

Use synthetic content in examples and tests. Never include a real library,
cookies, browser profiles, API keys, Google tokens, recovery material or signing
keys. Report suspected credential exposure privately through GitHub's security
reporting feature when available; do not paste credentials into an issue.

Explain the user-visible problem, keep the change focused, and record relevant
checks. Source setup is in [BUILDING.md](docs/development/BUILDING.md); local MCP
setup is in [MCP.md](docs/development/MCP.md). The
[export workflow](docs/development/EXPORT.md) explains how public contributions
are preserved across releases.
